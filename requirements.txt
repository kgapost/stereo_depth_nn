# ============================================================================
# requirements.txt
# Python (PyPI) dependencies for training the stereo depth models in this
# directory: train_tartanair.py (TartanAir) and train.py (AirSim recordings),
# plus stereo_datasets.py, models/ and evaluate.py, which they import.
#
# Deliberately much smaller than setup/requirements_dev.txt: those cover the
# ROS nodes and the AirSim client, and pull in airsim, timm, torchvision,
# pyoctomap, scipy. `import torch`, `import numpy`, `import cv2` is the whole
# surface for every model except --model yolo.
# (Recording new AirSim data with collect_dataset.py still needs the dev-PC
# requirements; this file is only for training on data that already exists.)
#
# ultralytics is the one exception, and it is needed only by --model yolo:
# models/yolo_stereo.py parses models/yolo26_stereo.yaml with ultralytics'
# own parse_model and reuses its Conv/C3k2/SPPF/C2PSA blocks. models/__init__
# imports that module lazily, so training baseline/temporal/mobilenet/anynet
# still works with ultralytics absent. Note it is AGPL-3.0, unlike the rest of
# the dependencies here - relevant if this training code is published or
# shipped on the drone.
#
# Setup - Python 3.12, matching obs_det_env:
#     python3 -m venv stereo_env
#     ./stereo_env/bin/pip install -r stereo_depth_nn/requirements.txt
#     cd stereo_depth_nn && ../stereo_env/bin/python3 train_tartanair.py --help
#
# The scripts import each other by bare module name (`from train import fit`),
# so run them with stereo_depth_nn as the working directory.
# ============================================================================

tartanair
# this will take care of pytorch, opencv, numpy etc.
tensorboard
ultralytics                   # --model yolo only (AGPL-3.0; see header)
